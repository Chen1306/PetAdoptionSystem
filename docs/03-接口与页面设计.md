# 流浪动物管理及领养系统接口与页面设计

## 1. 接口设计规范

- 基础路径：`/api`
- 传输格式：`application/json`
- 认证方式：请求头 `Authorization: Bearer {token}`
- 分页参数：`pageNum`、`pageSize`
- 返回格式：

```json
{
  "code": 200,
  "msg": "success",
  "data": {}
}
```

## 2. 错误码约定

| code | 含义 |
| --- | --- |
| 200 | 成功 |
| 401 | 未登录 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 500 | 服务器异常 |

## 3. 接口模块设计

### 3.1 认证模块

#### 用户注册

- `POST /api/auth/register`
- 请求参数：`username`、`password`、`phone`
- 校验规则：
  - 用户名 3-20 位
  - 密码 6-20 位
  - 手机号 11 位

#### 用户登录

- `POST /api/auth/login`
- 请求参数：`username`、`password`
- 返回：`token`、用户信息、角色信息

#### 退出登录

- `POST /api/auth/logout`

### 3.2 用户前台模块

#### 获取宠物列表

- `GET /api/pets`
- 支持条件：`type`、`keyword`、`pageNum`、`pageSize`
- 游客可访问
- 仅返回审核通过且可领养宠物

#### 获取宠物详情

- `GET /api/pets/{id}`
- 游客可访问

#### 提交领养申请

- `POST /api/adoptions`
- 请求参数：`petId`、`applyDescription`
- 权限：普通用户

#### 我的申请列表

- `GET /api/adoptions/my`
- 权限：普通用户

#### 取消领养申请

- `PUT /api/adoptions/{id}/cancel`
- 权限：普通用户
- 仅允许取消 `WAITING`

#### 获取个人信息

- `GET /api/users/profile`

#### 修改个人信息

- `PUT /api/users/profile`
- 请求参数：`username`、`phone`、`password`

### 3.3 管理后台模块

#### 用户管理

- `GET /api/admin/users`
- `PUT /api/admin/users/{id}/status`

#### 宠物管理

- `GET /api/admin/pets`
- `POST /api/admin/pets`
- `PUT /api/admin/pets/{id}`
- `DELETE /api/admin/pets/{id}`

#### 宠物审核

- `PUT /api/admin/pets/{id}/review`
- 请求参数：`reviewStatus`、`reviewRemark`

#### 领养申请管理

- `GET /api/admin/adoptions`
- `PUT /api/admin/adoptions/{id}/audit`
- 请求参数：`status`、`auditRemark`

#### 数据统计

- `GET /api/admin/statistics/overview`
- 返回：用户总数、宠物总数、领养申请总数、待审核申请数

## 7. 字段校验建议

### 用户

- `username`：3-20 位，不能为空
- `password`：6-20 位，不能为空
- `phone`：11 位手机号

### 宠物

- `petName`：不能为空
- `type`：`cat/dog/other`
- `age`：大于等于 0

### 领养申请

- `applyDescription`：不能为空，长度不超过 500
